# Pricing & Packages

Standard rates and the package language I send to clients. Update this file when rates change.

## Rates

| Item | Unit price |
| --- | --- |
| Class | $30 |
| Private session | $100 |

## Standard package

**10 classes ($300) + 10 privates ($1,000) = $1,300**

This is the default pairing I quote. Package price is a straight multiple of the
unit rates — no bundle discount is baked in.

## Other pairings at the same rates

| Pairing | Price |
| --- | --- |
| 10 classes only | $300 |
| 10 privates only | $1,000 |
| 5 classes + 5 privates | $650 |
| 10 classes + 5 privates | $800 |
| 5 classes + 10 privates | $1,150 |
| **10 classes + 10 privates (standard)** | **$1,300** |

Formula for anything else: `(classes × $30) + (privates × $100)`

## Message template

> New package! 🫶
>
> 10 classes ($300) + 10 privates ($1,000) = $1,300
>
> Is what you typically do, but let me know if you want another pairing.

For a first-time client, swap the second line for whatever pairing fits and
close with: "This is typically what I charge — happy to adjust the mix."
